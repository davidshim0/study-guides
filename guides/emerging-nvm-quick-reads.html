Emerging Non-Volatile Memory — Four Quick Reads

Light notes on four device-level NVM papers pulled from the queue: an embedded STT-MRAM production chip, a vertical ferroelectric HfO2 FET, a 3D vertical ReRAM with multi-level cells, and an architecture paper on the crossbar sneak-current problem. Each entry is just the shape of the idea and the numbers worth remembering — not a deep-dive.

STT-MRAM (TSMC, ISSCC'20) Vertical FeFET (imec, IEDM'18) 3D Vertical ReRAM (Tsinghua, Sci. Rep. '14) Crossbar Challenges (PSU/HP/Utah, HPCA'15)
ISSCC 2020 · Session 13, Non-Volatile Memories

A 22nm 32Mb Embedded STT-MRAM with 10ns Read Speed, 1M Cycle Write Endurance, 10-Year Retention at 150°C

Chih, Shih, Lee, et al. — TSMC, Hsinchu, Taiwan

MRAMembedded NVMproduction silicon

A production-grade 32Mb STT-MRAM macro built on TSMC's 22nm ultra-low-leakage CMOS, meant as an embedded flash replacement. The interesting engineering is all in making a physically tiny, noisy read/write margin work reliably across a wide temperature range and in the presence of stray magnetic fields — not in any new materials.

MetricValue
Bit cell size0.0456 μm²
Read speed<10ns access time at 125°C
Read power0.8 μA/MHz/bit
Write endurance>1M cycles (1Mb array); >100K cycles JEDEC-certified at 32Mb
Data retention10 years at 150°C (JEDEC-certified), survives 260°C/>90s IR reflow
Low-power standby leakage<55 μA at 25°C, wake-up <100ns
Write throughput>1.5 kB/ms (burst mode, 8-word buffer)
Magnetic shielding effectbit error rate cut from >10⁶ ppm to ~1ppm under 3500 Oe field (0.3mm shield film)
Why it's notableOnly 2 extra masks over standard logic CMOS, and the write algorithm deliberately trades a slightly higher per-pulse failure rate for lower MTJ voltage stress — recovering reliability with a "dynamic re-grouping" retry pass instead. That's the kind of circuit-level trick that makes MRAM viable as an embedded-flash drop-in rather than just a research curiosity.
IEDM 2018 · Session 2.5

Vertical Ferroelectric HfO₂ FET Based on 3-D NAND Architecture: Towards Dense Low-Power Memory

Florent, Pesic, Subirats, et al. — imec, Leuven, Belgium

FeFET3D NANDfirst demonstration

First demonstration of a vertical "macaroni-type" ferroelectric HfO₂ FET built in a 3D NAND-style architecture (three transistors stacked in series, 50nm channel length). The pitch is that swapping charge-trap storage for a ferroelectric layer could cut the power and periphery (charge pumps) that make conventional 3D NAND expensive at the system level — while staying fully CMOS-compatible.

MetricValue
Memory window~2V (pulsed I-V, ±10V/100ns program-erase) — vs only ~0.5V measured with slower DC I-V
Endurance10⁴ cycles before memory window closes (device-level capacitor test hit 10⁵ with no fatigue)
Program/erase speed100ns pulses — comparable to planar FeFET (10ns/10ns) and far faster than flash NAND (100μs/10ms)
Retention10 years expected at 85°C (extrapolated; PRG state degrades faster than ERS state)
Energy<1 fJ/bit — matches planar FeFET, ~1000x better than flash's <1 nJ/bit
Cell area0.026 μm² per layer, stackable at 160nm pitch
ON/OFF ratio~6 decades (~1μA ON, few pA OFF)
Why it's notableThe endurance ceiling (10⁴ cycles, window closes from charge trapping at the HfO₂/poly-Si interface) is the paper's own honestly-reported bottleneck — matched to flash NAND today but far short of planar FeFET's 10⁵. The authors are explicit that a thinner gate oxide is the obvious next lever: lower operating voltage, less trapping, better endurance. This is very much a "first demonstration, here's the roadmap" paper rather than a finished device.
Scientific Reports 4:5780 (2014)

Study of Multi-Level Characteristics for 3D Vertical Resistive Switching Memory

Bai, Wu, Wu, Zhang, Deng, Yu, Qian — Tsinghua University

ReRAM3D verticalMLC

A three-layer 3D vertical AlOₓ/Ta₂O₅₋ₓ/TaOᵧ ReRAM stack, demonstrating that a single physical pillar can reliably hold 4 distinct resistance levels (multi-level cell, or MLC) using either current-controlled SET or voltage-controlled RESET. The paper's other contribution is a SPICE-based analysis of which of those two control schemes actually scales to large arrays.

MetricValue
HRS/LRS switching window>1000× (LRS ~1kΩ, HRS ~1MΩ) — wide enough for clean 4-level MLC
Endurance>10¹⁰ switching cycles (100ns SET/RESET pulses)
Retention>10⁴ s at 125°C, no degradation on either HRS or LRS
MLC levels4 levels: ~1kΩ / ~100kΩ / ~1MΩ / ~10MΩ, stable over 100+ DC cycles
SET / RESET voltages−0.8 to −1.5V (SET) / 0.9 to 2V (RESET); forming voltage ~−1.8V
Max array size (50% resistance tolerance)VCS: >10⁴ bits vs. CCS: only ~1000 bits
Why it's notableThe array-scaling result is the sleeper finding here: current-controlled MLC (CCS) looks fine at the single-cell level but collapses at scale because unselected cells sharing a pillar "steal" current under the 1/3-bias scheme, so the actual SET current on the target cell drops as the array grows. Voltage-controlled RESET (VCS) doesn't have that failure mode and tolerates roughly 10x larger arrays — a good reminder that device-level numbers alone don't tell you if a scheme is architecturally viable.
HPCA 2015

Overcoming the Challenges of Crossbar Resistive Memory Architectures

Xu, Niu, Muralimanohar, Balasubramonian, Zhang, Yu, Xie — Penn State / HP Labs / Utah / Arizona State / UC Santa Barbara

architectureReRAMsystem-level

Not a device paper — this is the architecture-side companion to the device papers above. Crossbar ReRAM (no per-cell access transistor) is the dense way to build ReRAM main memory, but "sneak current" through half-selected cells means the IR drop on the write path is data-pattern-dependent: how many bits are flipping determines how long the write takes. The paper proposes circuit and encoding tricks to shrink that worst case.

MetricValue
ReRAM endurance (cited)>10¹⁰ cycles — the property that makes crossbar ReRAM attractive as DRAM-class main memory in the first place
Baseline worst-case write latency (tWR)692ns (512×512 mat, conservative biasing)
+ Double-sided ground biasing (DSGB)692ns → 200ns; worst-case voltage drop improved (2.146V → 2.328V at the worst cell)
+ Split RESET phase on top of DSGB200ns → 138ns
Voltage sensitivitya 0.4V drop in RESET voltage was shown (cited from prior HfOₓ ReRAM work) to increase RESET latency by 10×
System-level resultfull scheme: ~44% faster than a conservative ReRAM baseline, ~14% faster than an aggressive one, within ~10% of an ideal DRAM-only system
Why it's notableThis is the paper that explains why the raw device numbers above (10ns reads, 10¹⁰ endurance) don't automatically translate into a fast memory system: crossbar sneak current means the worst-case write on the far corner of a large mat can be many times slower than the best case, purely from IR drop and how many bits happen to be flipping. Useful pairing with the ReRAM/MRAM device papers above if you want the "why doesn't this just ship as DRAM replacement" answer.
